# Atelier Galerie Vittet — mode d’emploi

Guide simple pour gérer les œuvres au quotidien.

**Adresse :** https://atelier-kv-preview.galerie-vittet-preview.pages.dev/atelier/  
**Site public :** https://galerie-vittet-preview.pages.dev/

Un identifiant et un mot de passe vous seront donnés à part. Sans eux, la page demande une connexion.

---

## En deux mots

L’atelier sert à :

1. **Ajouter** des photos d’œuvres  
2. **Corriger** les textes (artiste, titre, note…)  
3. **Choisir** ce qui apparaît sur le site (exposé, carousel, catégorie)  
4. **Ranger** l’ordre des œuvres sur la vitrine  
5. **Exporter** un catalogue PDF si besoin  

Seules les œuvres cochées **Exposée** sont visibles sur le site public.

---

## Première ouverture

1. Ouvrez le lien de l’atelier.  
2. Entrez l’identifiant et le mot de passe.  
3. Vous voyez en haut la **bibliothèque** (toutes les œuvres), en bas le formulaire pour **ajouter** de nouvelles images.

Le lien « Retour à la galerie » ouvre le site public (pour vérifier le résultat).

---

## Ajouter des œuvres

1. Cliquez **Choisir images ou dossier**.  
2. Prenez des fichiers (JPEG, PNG ou WebP) ou un dossier entier.  
3. Cochez au besoin : peinture / miniature / aquarelle.  
4. Options à l’ajout (facultatif) :  
   - **Marquer comme exposée** → visible tout de suite sur le site  
   - **Inclure dans le carousel** → grande image en haut du site (uniquement si aussi exposée)  
5. Cliquez **Aperçu** : vérifiez les textes remplis automatiquement depuis la photo.  
6. Corrigez ce qui ne va pas.  
7. Cliquez **Enregistrer**.

Sans la coche « exposée », l’œuvre est bien enregistrée mais **reste cachée** du public.

Limite pratique : une image ne doit pas dépasser environ 40 Mo.

---

## Modifier une œuvre déjà en bibliothèque

Chaque fiche permet de :

| Action | Effet |
|---|---|
| Modifier le texte puis **Enregistrer** | Sauve artiste, titre, note, dimensions… |
| Cocher / décocher **Exposée**, **Carousel**, catégories | Pris en compte **tout de suite** (pas besoin d’Enregistrer) |
| **Remplacer** | Change la photo (garde le reste de la fiche) |
| **Recadrer** (carousel) | Cadre uniquement la grande image du haut de page |
| Supprimer | Retire l’œuvre |

### Textes

- Changez les champs.  
- Le bouton **Enregistrer** s’active seulement s’il y a une modification.  
- Cliquez **Enregistrer** pour valider le texte.

### Coches

- **Exposée** : visible sur le site.  
- **Carousel** : dans le défilement d’images en haut (il faut aussi être exposée).  
- Peinture / miniature / aquarelle : onglets de la collection.

Ces coches s’enregistrent **dès que vous cliquez**.

### Remplacer la photo

1. Cliquez **Remplacer**.  
2. Choisissez la nouvelle image.  
3. Validez.  
L’ancienne photo est remplacée ; les textes restent.

### Recadrage carousel

Si l’œuvre est dans le carousel, un bouton **Recadrer** (ou **Recadré**) ouvre un cadre au format de la grande image d’accueil.

1. Zoomez et glissez pour cadrer.  
2. **Valider le recadrage**.  
La photo dans la collection (grille) reste entière ; seul le haut de page utilise le recadrage.

## Trouver une œuvre dans la bibliothèque

En haut de page :

- **Catégorie**, **Artiste**, **Période**, **Exposition** (exposées / non exposées / carousel)  
- **Recherche** : tapez un mot (titre, artiste, note…)  
- **Tri** : plus récente, plus ancienne, ordre du site, artiste, titre  

Les filtres **masquent** ce qui ne correspond pas.  
Il y a **25 œuvres par page** : utilisez Précédent / Suivant.

---

## Ordre sur le site public

1. Filtrez de préférence sur **Exposées**.  
2. Choisissez le tri **Ordre front**.  
3. Glissez les fiches, ou utilisez les flèches ↑ ↓.  

Cet ordre est celui de la collection sur le site.

---

## Catalogue PDF et export

- Cochez les œuvres voulues (ou « Tout sélectionner »).  
- **Générer le catalogue PDF** : fichier à télécharger / imprimer.  
- **Exporter la base** : sauvegarde complète des fiches (copie de sécurité).  
- **Générer versions web manquantes** : outil technique, à n’utiliser que si on vous le demande.

## Ce que voit le public

| Dans l’atelier | Sur le site |
|---|---|
| Exposée cochée | Visible dans la collection |
| Exposée + Carousel | Aussi dans le grand défilement du haut |
| Non exposée | Invisible pour les visiteurs |
| Ordre front | Ordre des tableaux dans la collection |

Après un changement, rechargez le site public (parfois une fois suffit ; sinon attendez une minute).

---

## Petits conseils

- Travaillez d’abord en **non exposé**, vérifiez la fiche, puis cochez **Exposée**.  
- Une œuvre au carousel sans être exposée **n’apparaît pas** au public.  
- Pour le carousel, un bon recadrage évite les bandes noires sur mobile.  
- En cas de doute : ne supprimez pas — décochez seulement **Exposée**.

---

## En cas de blocage

1. Rechargez la page de l’atelier.  
2. Vérifiez que vous êtes bien connecté.  
3. Contactez la personne qui gère le site (Emmanuel) avec le titre de l’œuvre et ce que vous vouliez faire.
