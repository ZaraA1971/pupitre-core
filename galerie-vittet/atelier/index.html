Gérer les œuvres

Source de vérité D1 : métadonnées Artlogic en français (artiste, titre, note, signé et date, support, dimensions, éditions) + coches peinture / miniature / aquarelle, exposition, carousel hero, ordre d’affichage front (glisser-déposer ou ↑↓), filtres qui masquent hors critère, pagination 25 / page, puis catalogue PDF. Le front public n’affiche que les œuvres exposées, dans cet ordre.

Tri

Tri par défaut : plus récente téléchargée ou modifiée (max création / modification). En « Ordre d’affichage front », glissez ou utilisez ↑↓ pour regrouper les œuvres sur la vitrine (filtre Exposées recommandé) — l’ordre est enregistré dans D1 (`sort_order`). La période ne retient que les siècles déjà écrits dans les métadonnées. Les filtres masquent hors critère, puis 25 fichiers par page.
